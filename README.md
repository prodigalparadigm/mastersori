# mastersori.com

The public home of The Mastersori Method, by Kathleen Bartin (Prodigal Paradigm LLC).

Plain static site for GitHub Pages. No build step: edit the files and push.

- `index.html` - front page: the thesis and the arc at a glance
- `method.html` - the method, stage by stage
- `argument.html` - the argument: the reasoning under the steps
- `dedication.html` - the name: Margaret Masterman and Maria Montessori
- `workbench.html` - starter worksheets that run in the page (nothing is submitted)
- `styles.css`, `app.js`, `assets/` - the style system from Kathleen's style build
- `llms.txt`, `sitemap.xml`, `robots.txt` - the find-me layer; update `sitemap.xml` dates and `llms.txt` when pages change

House rules for this site: no client staff names, receipts only, hyphens not em-dashes, plain language, and nothing goes live without Kathleen's word.
